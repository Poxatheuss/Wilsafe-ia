# WILSAFE IA — Inspeção SST

Protótipo mobile-first para inspeções de Segurança e Saúde no Trabalho.

## Versão inicial
- Nova inspeção assistida
- Empresa, unidade, setor e função
- Observações e medidas existentes
- Pré-análise por grupos de risco
- Perguntas de confirmação
- Aprovação para inventário
- Regra: não inventar medições, concentrações, CAs ou resultados quantitativos
- Preservar a data original de medições importadas

A próxima fase conectará a análise a um backend seguro com IA, banco de dados, inventário e plano de ação. Nenhuma chave de API deve ser armazenada no front-end.
